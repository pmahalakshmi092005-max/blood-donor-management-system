Blood Donor Availability Management System

A responsive, database-driven web application built to bridge the critical gap between voluntary blood donors and recipients in emergency medical situations.

System Architecture
  • Frontend Layer:
    HTML5, CSS3, JavaScript, Bootstrap 5 responsive UI with real-time feedback.
  • Backend Layer:
    Python 3.13, Django 6, Django REST Framework (DRF) with clean MVC/MVT architecture.
  • Database Layer:
    SQLite relational database with Django ORM schema management and migrations.
Core Objectives
  • Complete CRUD Support: Add, view, edit, and delete donor records safely.
  • Location & Blood Filtering: Instant search by City, Blood Type, and Availability status.
  • Live Statistics Dashboard: Real-time overview of donor readiness across all 8 blood groups.
  • RESTful API: Standardized JSON endpoints ready for mobile app or third-party health integration.
